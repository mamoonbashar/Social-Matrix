# SocialMatrix

SocialMatrix is a full-stack social media platform built using the MERN stack.

## Tech Stack
- Backend: Node.js, Express, MongoDB
- Frontend: React, Vite
- Authentication: JWT
- Database: MongoDB

## Current Status
🚧 In development

## Features (Planned)
- User authentication
- Create, like, comment on posts
- Follow / unfollow users
- Personalized feed
- Tasks & productivity module

## Project Structure
- `/server` – REST API and database logic
- `/client` – React application
